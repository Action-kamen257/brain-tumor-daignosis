================================================================================
                    BRAIN TUMOR DETECTION (NEURASCAN)
                           RUN INSTRUCTIONS
================================================================================

PREREQUISITES:
1. Python environment (.venv) with required packages:
   - Flask, Flask-CORS, PyTorch, TorchVision, OpenCV, Pillow, NumPy
2. Node.js & npm (for the React/Vite frontend)

--------------------------------------------------------------------------------
HOW TO RUN (OPTION 1: AUTOMATIC BATCH SCRIPT)
--------------------------------------------------------------------------------
You can rename this file to 'run.bat' or run 'run.bat' directly, which contains:

@echo off
echo ============================================================
echo Starting NeuraScan Brain Tumor Detection System...
echo ============================================================

echo [1/2] Launching Flask Backend on http://localhost:8000 ...
start "NeuraScan Backend" cmd /k "cd /d %~dp0 && .\.venv\Scripts\python.exe app.py"

echo [2/2] Launching React Vite Frontend on http://localhost:3000 ...
start "NeuraScan Frontend" cmd /k "cd /d %~dp0brain-tumor-app && npm run dev"

echo.
echo Application is starting!
echo - Frontend: http://localhost:3000
echo - Backend:  http://localhost:8000
echo ============================================================
